- [ ] ESP32 корректно парсит и маршрутизирует команды.
- [ ] `Audio_Task` формирует правильные Yamaha-команды.
- [ ] `Ir_Task` стабильно управляет KY-005.
- [ ] Yamaha RX-E400 реагирует минимум на Power, Volume и Next.
- [ ] Повреждённые и неизвестные пакеты не вызывают действий.
- [ ] Все задачи используют очереди и не обращаются к чужому состоянию напрямую.
- [ ] Диагностика показывает только подтверждённые локальные события.
- [ ] Переход от эмулятора к настоящему VC-02 не требует изменения прикладной логики.
